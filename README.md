# CLI File System Manager

Консольное приложение на чистом C# для навигации и управления файловой системой с поддержкой Unix-подобных команд и флагов.

## Архитектурные особенности

* **Принципы SOLID и GoF-паттерны:** Парсинг аргументов командной строки реализован с соблюдением принципа открытости/закрытости через цепочку обязанностей и паттерн Команда.
* **Абстракция ввода-вывода:** Логика работы с файловой системой и рендеринг дерева каталогов полностью отвязаны от консоли (паттерны Strategy и Visitor).
* **Оптимизация памяти:** Ленивое построение объектной модели дерева каталогов с параметризуемой глубиной выборки без выгрузки всего среза ФС в оперативную память.
* **Тестирование:** Набор юнит-тестов (`xUnit`) для проверки корректности парсера команд и флагов.
